Runtime
-------
transformers.js (Hugging Face, Apache-2.0) plus its bundled ONNX Runtime Web build
are vendored in the site repositories at static/vendor/transformers/ with their
own LICENSE. This directory holds model DATA only.

Prior art / inspiration
-----------------------
Zackriya-Solutions/meetily (MIT) - a privacy-first DESKTOP meeting assistant
(Tauri + Rust + whisper.cpp + Ollama). It has no browser or WebAssembly build, so
freetoolonline.com's /utility-tools/meeting-notes-taker.html is an independent
browser implementation of the same job (record -> local transcript -> minutes),
not a port: no meetily source code or asset is served to readers.

Nothing in this directory is generated by freetoolonline.com.
