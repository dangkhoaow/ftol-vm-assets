Reference implementation
------------------------
supertone-inc/supertonic (web/helper.js, web/main.js) - MIT License.
The browser inference pipeline on freetoolonline.com (/utility-tools/
text-to-speech.html) is an independent vanilla-JS implementation of the same
documented model contract (unicode indexer -> duration predictor -> text
encoder -> flow-matching vector estimator -> vocoder); no upstream source file
is served to readers.
